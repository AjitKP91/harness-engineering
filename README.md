# AI Agent Harness Engineering

A zero-to-mastery, beginner-friendly textbook (**42 chapters**, **78 glossary terms**) and interactive web application explaining how modern AI coding agents work under the hood.

- **Live Website (GitHub Pages):** https://ajitkp91.github.io/harness-engineering/
- **Markdown Study Guide:** [`harness-engineering-study-guide/`](./harness-engineering-study-guide/README.md)
- **Interactive Web App Source:** [`harness-engineering-site/`](./harness-engineering-site/)

## Repository Structure

```text
.
├── harness-engineering-study-guide/   # 42 plain-English chapters + glossary + curriculum plan
├── harness-engineering-site/          # Interactive Vite/TypeScript textbook + 6 live harness simulators
└── .github/workflows/deploy-pages.yml # Automated GitHub Pages build & deployment
```

## Run Locally

```bash
cd harness-engineering-site
npm install
npm run dev
```
